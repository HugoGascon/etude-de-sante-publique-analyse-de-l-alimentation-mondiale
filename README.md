Dans le cadre d’un projet en data science appliquée à la santé publique, j’ai conduit une analyse portant sur l’évolution de l’alimentation mondiale sur la période 2013–2017, en utilisant Python.
Cette étude s’inscrit dans la continuité d’un premier travail réalisé sur les données les plus récentes (2018 à aujourd’hui), et vise à apporter une perspective historique permettant d’enrichir la compréhension des dynamiques alimentaires à l’échelle internationale.
Les travaux réalisés ont couvert l’ensemble des étapes d’un projet d’analyse de données :

Préparation, nettoyage et structuration des bases de données  
Analyse exploratoire afin d’identifier les principales tendances  
Production de visualisations pour faciliter l’interprétation des résultats  
Réalisation d’analyses complémentaires en lien avec les enjeux de santé publique

L’objectif était d’identifier les évolutions significatives en matière de disponibilité alimentaire, de mettre en évidence d’éventuelles disparités entre pays, et de contribuer à une meilleure compréhension des problématiques nutritionnelles à l’échelle mondiale.
Technologies mobilisées : Python (Pandas, NumPy, Matplotlib, Seaborn).
